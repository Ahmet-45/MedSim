# 🏥 MedSim - Yapay Zeka Destekli Vaka Simülasyonu

Bu proje, tıp fakültesi öğrencileri için geliştirilmiş, yapay zeka destekli sanal bir hasta simülasyon sistemidir.

## 🚀 Proje Özellikleri

### Frontend (Arayüz)
* **HTML5, CSS3, Bootstrap 5:** Responsive ve modern tasarım.
* **JavaScript:** Dinamik veri akışı ve kullanıcı etkileşimi.

### Backend (Sunucu)
* **Python & Flask:** Güçlü sunucu altyapısı.
* **Yapay Zeka (AI):** SDV, CTGAN ve PyTorch ile eğitilmiş sentetik hasta verisi üretimi.

## 🛠️ Kurulum

Proje gereksinimlerini yüklemek için:
```bash
pip install -r requirements.txt

Projeyi çalıştırmak için:
```bash
python app.py
